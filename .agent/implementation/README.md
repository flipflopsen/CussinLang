# CussinLang Compiler Implementation

## Project Overview
This directory contains all documentation and planning artifacts for the CussinLang compiler implementation. The compiler is a C++17 project that implements a statically/strongly typed toy programming language with a hand-written lexer, recursive-descent parser, AST-based intermediate representation, and LLVM-backed code generation/JIT.
